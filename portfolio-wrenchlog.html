About

WrenchLog is a car-maintenance tracker built to serve three goals at once: a practical tool for my own family's vehicles, a portfolio-grade engineering project, and the foundation for a future public SaaS. Every vehicle gets a maintenance schedule, odometer history, and service log; the schedule engine projects due dates from real mileage trends rather than guesses.

The engineering is deliberately production-shaped. Vehicles are decoded from their VIN via the NHTSA vPIC API (behind an injectable interface with a fake for tests), with proper check-digit validation. Auth is hardened by hand — bcrypt, transactional refresh-token rotation, timing-oracle and enumeration defenses — and multi-user "garages" enforce row-level tenancy on every query. Odometer writes are serialized per-vehicle with explicit locking, and a mileage engine estimates daily usage from reading windows. All of it is covered by an integration-test suite that runs against a real MySQL instance in CI.

The roadmap's centerpiece is an AI assistant: maintenance schedules generated by an LLM (reviewed by the user before saving) with tiered model quality by subscription level, all behind a single provider abstraction so local development runs fully offline. The build itself is also an AI story — each phase is planned as a written spec and executed with subagent-driven development, with the plan document kept byte-synced to the code as a living spec.
