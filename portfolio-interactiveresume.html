About

Interactive Resume replaces the static PDF with a small explorable app. The centerpiece is the Skills Explorer: skills render as selectable tags grouped by category (languages, frameworks, AI/LLM engineering, cloud/data, clinical/domain, practices), and selecting them highlights the timeline entries and projects that actually used those skills while dimming the rest — with match any / match all modes, live match counts, and one-click clear. Skill tags inside cards are clickable too, so a reader can pivot the filter from anywhere on the page. Experience and education share a single filterable timeline, and publications, patents, and talks carry kind badges and award callouts.

The design constraint that makes it maintainable: all content lives in one typed file, src/data/resume.ts, and the components contain zero resume content. Skill ids are string literals captured with as const, and the derived SkillId union means every cross-link is compile-checked — a typo'd or deleted skill id is a TypeScript error, so links from roles and projects to skills can never silently dangle. Running the build doubles as a data-validation pass.

It still has to work as a resume, so an @media print stylesheet collapses the whole app into a clean, compact document: interactive chrome disappears, chips become plain text, and cards flatten into typographic sections — one Ctrl+P away from a PDF. Light and dark themes come free via prefers-color-scheme and CSS custom properties.
