About

Kanban Board is a full-stack drag-and-drop task board: drag cards within and between columns, drag columns to reorder the board, and manage everything else through a card detail modal — title, description, labels, and due date. Due-date badges highlight overdue (red) and due-soon (amber) cards, label chips get a stable, deterministic color per label, and inline “add card” / “add column” flows keep editing fast. The UI updates optimistically and automatically re-syncs from the server if a request fails, so a dropped connection never leaves the board lying about its state.

The repo is an npm-workspaces monorepo with a clean seam down the middle: the React client never talks to SQLite directly — everything goes through a small Express REST API with input validation and a consistent 400 error shape. In development, Vite proxies /api/* to the Express server, so the app runs on one origin with no CORS configuration. The database is file-based SQLite via better-sqlite3, created and seeded with a demo board on first start — clone, npm install, npm run dev, done.

The subtle problem in any kanban app is ordering. Position is stored as a dense integer per column and per card-within-column, and the move/reorder endpoints rewrite positions transactionally — so the persisted order always matches what the user sees, and card position and column membership survive restarts.
