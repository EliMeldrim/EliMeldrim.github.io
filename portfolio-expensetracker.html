About

Expense Tracker API is a secured personal-finance REST API: register or log in to get a signed JWT, then manage your own expenses and categories — amounts, dates, notes, date-range and category filtering, pagination — plus a monthly summary endpoint that returns the total, per-category totals, and a comparison against the previous month. Six default categories (Food, Transport, Housing, Health, Entertainment, Other) are seeded and shared by everyone, alongside full CRUD for user-defined ones. The Swagger UI ships with working JWT support — paste a token into the Authorize button and every endpoint is callable from the browser.

The security posture is the point of the project. Passwords are hashed with ASP.NET Core Identity's PasswordHasher (PBKDF2), JWT settings are options-bound with startup validation, and every data endpoint is scoped to the authenticated caller — requesting another user's expense or category returns 404, not 403, so the API never even confirms the resource exists. Controllers stay thin: business logic lives in a service layer, errors funnel through a global exception middleware into RFC 7807 ProblemDetails, and request contracts are validated DTOs rather than raw entities.

A 29-test xUnit suite runs against the SQLite in-memory provider using the same schema and seed data as the real app. It covers the summary math — totals, per-category grouping, previous-month comparison across year boundaries — and, most importantly, auth scoping: users can never read, modify, or delete another user's expenses or categories.
