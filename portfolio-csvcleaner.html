About

CSV Data Cleaner turns the chore of fixing a messy spreadsheet into a composable pipeline. Upload a CSV or TSV — parsing is tolerant, with encoding sniffing, delimiter detection, and malformed lines skipped and reported — and a profiling panel breaks down every column: inferred type (including “numeric stored as text” detection), null counts and percentages, uniques, and IQR-based outlier counts for numeric columns. Then compose cleaning steps in order: drop duplicate rows, trim whitespace, normalize column names to collision-safe snake_case, coerce types with failure counts reported, handle nulls (drop, fill, or fill with mean/median/mode), and flag or clip outliers. Every step reports a diff summary — “Removed 12 duplicate rows” — and the result downloads as both the cleaned CSV and the pipeline as JSON, so the exact cleaning recipe is reproducible.

The design decision that makes the reproducibility real: cleaning operations are pure functions — DataFrame in, new DataFrame plus summary out, never mutating their input — and the API layer is just a thin dispatcher over them. Sessions are held in-memory with oldest-first eviction and uploads capped at 20 MiB; the README documents these as deliberate demo-scale simplifications (single worker process; a shared store would be the next step) rather than hiding them. The frontend is a single-page vanilla JS app with no build step — the whole thing is one process and one command, with a bundled ~200-row deterministic messy sample so the demo works on the first click.

A 41-test pytest suite covers every cleaning operation including its error paths, the profiling module, and a full API happy path — upload, a six-step pipeline, before/after previews, both downloads, and reset — via FastAPI's TestClient.
